# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A single-file PowerShell agent with a WinForms window (`now-console-agent.ps1`, version `ps-0.8.0`) that runs on a ski-race timekeeper's Windows PC. It copies the newest SKI PRO `Event*Ex.scdb` (+ `Event*.scdb`) from one folder and uploads the copies to `https://now-ski.com/api/console/file`, so NOW can match race videos to racers by start time. This directory is the **shipped package**, not the source repo: the server side (`lib/console-agent.ts`), `pack.mjs`, `consoles.json` and `CHANGELOG.md` referenced in comments live elsewhere and are not here. `VERSION-ps-<ver>.txt` is the changelog excerpt that travels with the package (it carries the previous versions' entries too).

Files: `now-console-agent.ps1` (all logic), `start-agent.bat` (double-click launcher for the window), `settings.txt` (per-PC config + token roster, generated by `pack.mjs`, now also edited by the window), `instructions-es.md` (end-user manual, Spanish), `tests\Test-Agent.ps1`. It is a git repository, public at `github.com/abrojodigital/now-console-agent` (branch `main`, version in tags: `ps-0.8.0`). **`settings.txt`, `*.log` and the legacy `now-console-agent.config.json` are git-ignored because they hold live tokens — never `git add -f` them**; `settings.example.txt` shows the format (its `# Name - Place   (vence YYYY-MM-DD)` comments are what the roster parser reads). Commits are conventional, with no AI attribution. `..\now-console-agent-0.7.0.backup` (outside the repo) is a copy of the ps-0.7.0 package taken before the GUI rewrite.

## Commands

```
start-agent.bat                                             # the window (what the timekeeper runs)
powershell -STA -NoProfile -ExecutionPolicy Bypass -File tests\Test-Agent.ps1    # the tests, exit code = failures
powershell -NoProfile -ExecutionPolicy Bypass -File now-console-agent.ps1 -NoGui -Token <token>          # old console output
powershell -NoProfile -ExecutionPolicy Bypass -File now-console-agent.ps1 -NoGui -Once -Token <t> -Url http://127.0.0.1:9/api/console/file   # one tick against a dead local port
```

Other parameters: `-Folder`, `-Url`, `-IntervalSeconds`, `-Event <nnn>`. **`-NoGui -Once` without `-Url` uploads to the real server** — point `-Url` at a closed local port when testing. There is no build and no lint; the only syntax check is `[System.Management.Automation.Language.Parser]::ParseFile(...)`. The tests use FAKE tokens and `http://127.0.0.1:9`, so nothing leaves the PC, and include a regression test (offline heartbeat must not kill the engine) — a mutation that removes the `Invoke-Curl` fix makes 3 of them fail.

Setting precedence: command line > `settings.txt` > legacy `now-console-agent.config.json` > built-in default.

## Architecture

**One engine, two front ends.** `$EngineScript` (a script block) is the whole agent loop. It never touches the UI: it writes news to a `ConcurrentQueue` (`Say` = a log line, `Dot` = "nothing happened") and state to a synchronized hashtable `$Shared` (`Online`, `LastSendAt`, `RaceLine`, `ClockLine`, `Tick`, `Busy`, `Stop`, …). `Start-Engine` runs it in its own runspace, so a 20 s upload never freezes the window. Front ends: `New-MainWindow`/`Update-UiStatus` (WinForms, a 250 ms `Timer` drains the queue and polls `$Shared`) and `Invoke-Headless` (`-NoGui`, prints to the console). Stopping is `$Shared.Stop = $true`, honoured within ~0.1 s outside an upload.

**Testability seam.** After the function definitions, `if ($MyInvocation.InvocationName -eq ".") { return }` — dot-sourcing the script loads the functions and runs nothing. That is how the tests work; keep the guard above the MAIN section.

**Settings and the token roster.** `Read-SettingsFile` treats *every* `token =` line, active or commented, as a candidate console, named from the `# Name - Place   (vence YYYY-MM-DD)` comment directly above it. The window shows them as a dropdown and saves the choice as `consola = <name>`; `Select-Console` resolves it (explicit choice > exactly one active token > nobody). Two active tokens and no saved choice means **no preselection and Iniciar refuses** — never a silent default. `Save-SettingsFile` edits `settings.txt` line by line and leaves everything else (the roster above all) byte-identical; it writes CRLF + BOM via a `.tmp` and `Move-Item`. `-NoGui` keeps the legacy rule (first active token wins, with a warning).

## What has to stay true

- **Never touch the live database.** `Send-Once` picks the most recently written `Event*Ex.scdb`, skips the tick if a `-journal` file exists beside either DB, copies to `%TEMP%\now-console-agent`, and only ever reads the copy.
- **Read-only, one folder, nothing installed.** Sends only `Event*.scdb`. The only things it writes: `settings.txt` (from the window), its `.log`, the temp copies. No auto-update: `agent_too_old` stops the engine (`ExitCode` 3) and tells a person — by design.
- **Send only on change.** SHA-256 of each copy is kept per file; the main file (`EventNNN.scdb`) is attached only when *its* hash changed, the `Ex` file whenever it changes.
- **Clocks are the whole point.** Each upload carries `pcClockMs`, `tzMinutes`, `exMtimeMs` and the agent's own NTP-style offset (`Sync-Clock`, 3 samples, lowest RTT, every 10 min). The 1 s interval floor exists because the arrival stamp brackets when an impulse happened. The PC clock and the timing box's clock are different things.
- **Heartbeat + connection alarm.** No POST for 60 s → `Send-Heartbeat` (`heartbeat=1`, no file). `Set-Online` announces each transition once.
- **Version travels with every upload** (`agentVersion`). Behaviour change ⇒ bump `$AgentVersion`, rename/extend `VERSION-ps-<ver>.txt`, and remember the server must learn the new number or the reply keeps saying "outdated".
- **Same protocol as 0.7.0**: same endpoint, form fields and files. Changing it is a server change too.

## Gotchas (each one has already bitten)

- ⚠️ **Every native call goes through `Invoke-Curl`.** In Windows PowerShell 5.1, `2>&1` + `$ErrorActionPreference = "Stop"` *throws* on the first stderr line curl writes (i.e. whenever the network is down). ps-0.7.0 called the heartbeat outside any try/catch, so a dropped connection killed the agent. Never call `curl.exe` directly.
- ⚠️ **PowerShell variables are case-insensitive**: `$S` and `$s` are the same variable. The engine state is `$St` for that reason.
- **The script is UTF-8 with BOM, on purpose.** PS 5.1 reads a BOM-less `.ps1` as ANSI, so accents in the window would be mojibake. The Edit tool preserves the BOM; a different editor may not — `tests\Test-Agent.ps1` checks it (and the test file has its own BOM because it contains `Ñandú`). Window strings are Spanish (Rioplatense voseo) with accents; the *engine's* `Say` strings kept ps-0.7.0's ASCII-only wording (they are also what the `.log` and the manual quote) — match the surrounding text. Code comments are English.
- **WinForms handlers run after their defining function returned**, so they use `$script:Ui` / `$script:App`, never locals, and each body is wrapped in try/catch (an escaping exception pops the .NET "unhandled exception" box in front of the timekeeper).
- `. $print` (dot-source), not `& $print`, in `Invoke-Headless`: a called script block gets its own scope and `$dots++` would bump a private copy.
- A Flat WinForms button keeps its `BackColor` when disabled (`Set-UiRunning` recolours Iniciar).
- **Verifying the UI:** `Control.DrawToBitmap` does not paint `RichTextBox` text (the log looks empty in a screenshot); read `.Text`, or use `CopyFromScreen`.
- Don't strip a trailing `\` from a bare drive root (`C:\` ≠ `C:`); `Format-FolderPath` guards it with `Length -gt 3`.
- `settings.txt` contains live tokens (and so does the `.backup` folder). Don't copy them into other files, logs, commits or chat.
